# ESPHome_kids_mp3_player
ESPHome mp3 player based on ESP32 and DFPlayer. It was designed for play Disney audio books.

DFPlayer is connected with ESP32 on GPIO16 and GPIO17.
For correct work is needed on SD card folder mp3 and files copied in. The best is file names starting as 0001* 0002* .... 0150* and etc.
Basic editing list is posible to adapt to your project or playlist.
